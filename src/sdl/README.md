SDL frontend for the portable core, and the first platform port. It links `src/core` (not `src/core/main.c`) and does not reimplement rules. `make sdl` builds `build/railgunner-sdl` and opens the 640×400 window (the 320×200 image at 2×). Keyboard: arrows or WASD, Space, S, I, Escape. The port record is [`agents/c64-to-sdl.md`](../../agents/c64-to-sdl.md).
